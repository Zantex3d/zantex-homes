## Phase 6: Jobs, Queue, Scheduler & Webhooks ✅ COMPLETE

### Job Classes (app/Jobs/)
1. **SendEmailJob**
   - Sends emails to users
   - Logs to AuditLog on completion/failure
   - Supports model tracking (User, Tenant, Landlord, Investor)

2. **SendSmsWhatsAppJob**
   - Sends SMS or WhatsApp messages
   - Adapter pattern for provider flexibility (WhatsApp/SMS)
   - Updates NotificationQueue status
   - Error tracking

3. **RentReminderJob**
   - Finds invoices due in 7 days (WHERE due_date = NOW() + 7 days AND status = 'Pending')
   - Dispatches SendEmailJob for each tenant
   - Daily execution at 2:00 PM (14:00)

4. **LeaseExpiryNoticeJob**
   - Finds leases expiring in 30 days
   - Sends notices to both tenant and landlord
   - Daily execution at 8:00 AM

5. **ServiceChargeCalculationJob**
   - Calculates service charges based on configuration rate
   - Creates ServiceCharge entries with due dates
   - Posts double-entry journal (DR Receivable, CR Revenue)
   - Weekly execution Monday at midnight

6. **MonthlyReportGenerationJob**
   - Generates landlord and investor statements
   - Creates PDF reports and stores in DocumentFiles
   - Emails links to stakeholders
   - Monthly execution on 1st at midnight

### Laravel Scheduler (routes/console.php)
```php
Schedule::job(new RentReminderJob)->dailyAt('14:00');
Schedule::job(new LeaseExpiryNoticeJob)->dailyAt('08:00');
Schedule::job(new ServiceChargeCalculationJob)->weeklyOn(1, '00:00');
Schedule::job(new MonthlyReportGenerationJob)->monthlyOn(1, '00:00');
```

### Paystack Webhook Receiver
- **Endpoint**: POST `/api/webhook/paystack` (public, no auth required)
- **Security Features**:
  - HMAC SHA-512 signature verification (`hash_hmac('sha512', payload, secret)`)
  - Idempotency checking (unique event_id in WebhookEvent table)
  - Automatic retry mechanism with dead-letter queue concept

- **Event Handling**:
  - `charge.success`: Update Payment status=approved, post DR Bank/CR Receivable
  - `charge.failed`: Update Payment status=rejected
  - `transfer.success`: Update Payout status=completed
  - `transfer.failed`: Update Payout status=failed

- **Models**: WebhookEvent (payload, status, error_message), Payout (payee, amount, bank, status)

### Configuration
- `.env` configured with PAYSTACK keys
- Queue driver set to 'database' (uses jobs table)
- Session driver set to 'database'
- Cache driver set to 'database'
